# Sistema de Nómina

Sistema de nómina en Java con programación orientada a objetos.

## Tipos de empleado
- Asalariado
- Por horas
- Por comisión
- Temporal

## Principios aplicados
- SOLID
- Código limpio
- Refactorización
- Pruebas unitarias con JUnit 5

## Metodología
Desarrollo ágil, con entregas pequeñas e incrementales.
